# 玲钰记账

一个无需后端即可运行的个人账单管家小程序原型。

## 运行

在当前目录执行：

```bash
node dev-server.js
```

然后打开 `http://localhost:4173`。

账单数据保存在浏览器 `localStorage` 中。应用首次打开为空账本，点击右上角“记一笔”即可新增自己的真实收入或支出。

首页日期按钮支持选择年月日，确认后显示该日期所在月份的总览；“今天”可回到当前日期，左右箭头用于切换月份。

账单明细支持关键词搜索、收支类型筛选、分类筛选、月份筛选、分页、编辑、删除记录和导出 CSV。编辑账单时可以修改金额、收支类型、分类、账户、备注和日期。

消费分析会按月份统计支出总额、日均支出、分类占比、每周趋势和分类排行。账户管理支持添加现金、银行卡与支付账户，并根据初始余额及关联账单实时计算余额。分类管理支持分别维护收入、支出分类，新增的账户和分类会立即出现在记账表单中。

手机端可通过底部导航访问总览、明细和分析，并从“管理”菜单进入账户与分类管理。

界面采用浅薄荷、粉色、天蓝和鹅黄色搭配的贴纸风格，保留用户提供的角色素材。按钮有按压反馈，弹窗和列表有短动画；系统开启“减少动态效果”时会自动减少动画。右上角扬声器按钮可开启或关闭操作音效，偏好保存在本机。音效由 Web Audio 合成，首次点击后启用，无需下载音频。

设计参考：[RetroUI / Neobrutalism](https://github.com/neobrutalism/neobrutalism) 的描边与短阴影思路，未引入其框架代码。扬声器、静音和编辑图标来自 [Lucide](https://github.com/lucide-icons/lucide)，许可证见 `assets/lucide-LICENSE.txt`。

## 随时随地使用

把整个目录部署到 GitHub Pages、Netlify、Vercel 等静态托管服务，拿到 `https://` 地址后，在手机浏览器打开并选择“添加到主屏幕”。项目已经包含 PWA 清单和离线缓存文件，部署后可以像独立 App 一样启动。

更新界面时请同时上传 `index.html`、`styles.css`、`app.js`、`sw.js`、`manifest.webmanifest` 和 `assets` 文件夹。账单仍存储在当前设备及网站地址下，不会随 GitHub 上传而同步到其他设备。
